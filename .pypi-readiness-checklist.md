## Pre-Upload Checklist

Before uploading to PyPI, ensure:

1. **Update Repository URLs**
   ```toml
   [project.urls]
   Homepage = "https://github.com/YOUR-ORG/pytest-semantic-assert"
   Repository = "https://github.com/YOUR-ORG/pytest-semantic-assert"
   Documentation = "https://pytest-semantic-assert.readthedocs.io"
   "Bug Tracker" = "https://github.com/YOUR-ORG/pytest-semantic-assert/issues"
   ```

2. **Update Contact Information**
   ```toml
   authors = [
       {name = "Your Name", email = "your.email@example.com"}
   ]
   ```

3. **Build Package**
   ```bash
   python -m build
   ```

4. **Test Installation**
   ```bash
   pip install dist/pytest_semantic_assert-0.1.0-py3-none-any.whl
   pytest --help | grep semantic
   ```

5. **Test on TestPyPI**
   ```bash
   twine upload --repository testpypi dist/*
   pip install --index-url https://test.pypi.org/simple/ pytest-semantic-assert
   ```

6. **Upload to PyPI**
   ```bash
   twine upload dist/*
   ```
